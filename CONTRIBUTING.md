# Contributing

1. Work in a feature branch from a clean or explicitly understood worktree.
2. Read `AGENTS.md` and the relevant architecture document.
3. Keep changes bounded and add acceptance criteria.
4. Add or update focused tests.
5. Run `npm run verify` before requesting review.
6. Explain authority changes, evidence changes, schema changes, and rollback behavior in the PR.
7. Do not include secrets or unredacted private prompt material.
