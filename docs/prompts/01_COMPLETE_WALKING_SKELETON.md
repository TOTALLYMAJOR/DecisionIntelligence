# Agent Prompt — Complete and Verify the Walking Skeleton

Act as principal product engineer and adversarial systems reviewer.

## Objective

Close only the gaps required for one fixture-mode journey:

```text
new problem → search prior evidence → inspect Prompt DNA → inspect lineage
→ select compiler modules → compile work packet → analyze candidate in mock mode
→ inspect creator-profile evidence
```

## Constraints

Preserve historical/canonical/candidate/projection authority boundaries. Use existing fixtures and
components before adding abstractions. No production auth, real corpus, hosted deployment, provider
key, or automatic writeback. No route may imply canonical promotion.

## Acceptance criteria

- Every primary route is keyboard reachable.
- Search finds `tenant authority`, `blast radius`, and `component reachability`.
- One Prompt DNA page shows original text, normalized intent, principles, lineage, and evidence.
- Lineage graph has an accessible textual equivalent.
- Compiler produces Markdown and provenance for at least six modules.
- Review page produces deterministic mock candidate analysis.
- Profile claims show confidence, evidence, and alternative explanations.
- Focused tests and the full verification suite pass.

End with exact evidence and one next eligible slice.
