1. `00_SETUP_REPOSITORY.md` — initialize the WSL/VS Code checkout and prove fixture mode.
2. `01_COMPLETE_WALKING_SKELETON.md` — close only real-flow and accessibility gaps in the included skeleton.
3. `02_INGEST_REAL_CORPUS.md` — introduce immutable real prompt/repository evidence.
4. `03_HARDEN_DUAL_PROVIDER_ANALYSIS.md` — evaluate and harden independent OpenAI/Claude candidate analysis.
5. `04_PRODUCTION_HARDENING.md` — authentication, authorization, persistence, storage, observability, backup, and hosted verification.

Use `CLAUDE_CONTINUATION.md` or `OPENAI_CODEX_CONTINUATION.md` when resuming with the named coding agent. Do not skip a gate because the next phase is more interesting.
